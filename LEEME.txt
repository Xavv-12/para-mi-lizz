PÁGINA PARA LIZZ ✦
==================

1. Abre "index.html" con doble clic (Chrome, Edge o Firefox).
   Necesita internet solo para cargar las letras bonitas.

2. PARA PONER SUS FOTOS:
   - Copia sus fotos dentro de la carpeta "fotos" (ej. foto1.jpg, foto2.jpg).
   - Abre "index.html" con el Bloc de notas o VS Code.
   - Busca la línea que dice:   "fotos":[]
   - Cámbiala así (una entrada por foto, separadas por coma):

     "fotos":[
       {"src":"fotos/foto1.jpg","cap":"Nuestra primera cita"},
       {"src":"fotos/foto2.jpg","cap":"El día que no paramos de reír"}
     ]

   - "src" es el nombre del archivo y "cap" es la frase que aparece abajo.
   - Guarda y vuelve a abrir la página.

3. PARA CAMBIAR LA CARTA O LA FIRMA:
   En esa misma línea están "carta" y "firma". Cambia el texto entre comillas.
   Para separar párrafos escribe \n\n  (así, con la diagonal).

4. PARA SUBIRLA A INTERNET GRATIS:
   Arrastra la carpeta completa a https://app.netlify.com/drop
   o súbela a GitHub Pages, y mándale el enlace a Lizz.

Nota: el botón "Editar página" solo aparece en la versión de Claude;
en esta versión las fotos se ponen editando el archivo como arriba.
